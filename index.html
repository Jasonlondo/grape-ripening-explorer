New York Cool Climate Grape Ripening Repository

Historical grape ripening records, queried in your browser. No server, no login.

Proof of concept for Objective 1, public tier. This page runs a full SQL database (DuckDB) in the browser over a data file served as a static file. It shows the public, de-identified tier of the repository. The two source programs, NYWGF and the Cornell Veraison to Harvest program, are pooled to the AVA and region level for 2024 to 2025, so no individual vineyard appears. Each row is a regional mean for one program, cultivar, year, and thermal-time window, with the sample count and the number of contributing sites kept as columns. The full per-site data stays in a private tier that is not published, and a production release would also suppress groups with too few contributing vineyards. Publishing the public tier is a matter of pushing the pooled file and turning on GitHub Pages.

Public tier. Two New York programs (NYWGF and the Cornell Veraison to Harvest program), 2024 to 2025, pooled to the AVA and region level with no individual vineyard identity. Engine: DuckDB-WASM. The X-axis switches between calendar date and cumulative growing degree days (base 5°C, from April 1). Fitted lines are LOESS smoothers shown per colour group when one cultivar is selected, for visualization only. The dashed "now" line marks the current position, today's date on the date axis or the entered current GDD on the GDD axis, with a dot where it meets each fitted curve. In production the current GDD comes from a live weather feed. This is a demonstration subset, not the full GRAPE-CAST repository.
